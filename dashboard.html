The dashboard needs a free Firebase database to talk to the iPad. One-time setup, about 5 minutes:
1
Go to console.firebase.google.com and sign in with any Google account.
2
Add project → name it anything (e.g. lincoln-ops). Turn Analytics off.
3
In the project: Build → Firestore Database → Create database → production mode → US location.
4
Firestore → Rules tab → replace with: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /families/{family}/{document=**} {
      allow read, write: if true;
    }
  }
}
→ Publish.
5
Gear icon → Project settings → Your apps → click the </> web icon → register the app → copy the firebaseConfig it shows you.
6
Paste it into firebase-config.js in the GitHub repo (replacing null) and re-upload the file.
7
Open the app on the iPad once first — it moves the existing schedule, rewards and XP to the cloud. Then reload this page.
